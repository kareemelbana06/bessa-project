# بِسَّة

موقع عربي للتعرّف على سلالات القطط واستكشاف معلوماتها وصورها.

## التشغيل محليًا

يتطلب Node.js. ثبّت الاعتماديات وشغّل خادم التطوير:

```sh
npm install
npm run dev
```

## أوامر المشروع

- `npm run build` لإنشاء نسخة الإنتاج.
- `npm run preview` لمعاينة نسخة الإنتاج محليًا.
- `npm run lint` لفحص جودة الشيفرة.
